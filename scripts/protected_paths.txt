# Protected paths of the tinystream tree.

# Read by the preToolUse guardrail hook (.github/hooks/guardrails.json: agents
# may not edit these, nor write to them from a shell) and by the diff-policy
# gate (scripts/check.sh diff-policy: a change that touches one of them FAILs).
#
# Format: one repo-relative path or glob per line. A trailing "/" protects the
# whole directory. "!" marks an exception that stays editable.
# A facilitator can lift the protection for one approved run with the
# environment variable TS_ALLOW_PROTECTED (space separated globs, e.g.
# TS_ALLOW_PROTECTED="src/pool/**"); agents never set it themselves.
